# Promo Codes and Discounts

## Rules for promo codes
Only one promo code can be used per order. Codes cannot be used to buy gift cards and cannot be applied to an order after it has been placed. Expired codes are not reinstated. Each code shows its own minimum order value and end date.

## Newsletter welcome code
Newsletter subscribers receive a 10% welcome code for their first order. It is valid for 30 days and on Quillfen-brand products only.

## Codes and Quillfen Plus
The 5% Plus member price does not combine with promo codes. Checkout applies whichever discount is larger, and shows a message "Better discount applied" when the code is not used.
